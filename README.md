# IOPscience Accessibility Conformance Report (ACR)
IOP publishing is committed to providing accessible products and services to our cutomers. The ACR documents our conformance against the Web Content Accessibility Guidelines (WCAG), Revised Section 508 and EN 301 549 standards.

All previous versions of the ACR can be found in the ACR_Archive directory in this repository.

The current version of the ACR is also avaialble to download from the <a href="https://iopscience.iop.org/page/accessibility">IOPscience Accessibility Statement</a>.
